## HOW TO UPLOAD
1. Generate images using prompts above
2. Name files exactly as shown (e.g. `kurtas-earth-rose-straight-kurta__1.jpg`)
3. Save to `public/products/` in the project folder
4. Go to **Admin → Products → [product name] → Images**
5. Enter the URL as `/products/[filename]`
6. Mark Image 1 as Primary for each product
